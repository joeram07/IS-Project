### Data analysis on Cybersecurity Suspicious web threat interactions
We are both cyber majors and found this data set to be relevant to our major.
Analyzing this data could prove to be useful in our careers, as it shows us real world malicious activity.

In this project we came up with four questions pertaining to various different aspects of the data set.
Based of the questions and information provided, we came up with the overarching question.
How can we better detect suspisious activity?

Our questions included:
"What is the correlation between bytes in and bytes out?"
"What is the average time of attacks each day?"
"Out of the ip's given, which ones originate from the same attacker?"
"What percentage of attacks were carried out by each country?"

For the first question, we found that there were very obvious areas that stood out. This showed us the areas of data size that are the most used for malicious data.
For the second question, we are able to see the number of attacks from the hour of 2300 from the first day leading into the next day until 0900. It also shows us the hour for peak attack time.
For the third question, we are able to see the IP's that were used and how many times each one was used.
For the fourth and final question, we were able see each country that was involved in the data set and the percentage of involvment from each country.

### Conclusion:
Through our analysis of the cybersecurity dataset, we gained valuable insights into suspicious web threat interactions. By addressing our four key questions, we identified patterns in data transfer sizes, peak attack times, recurring IP addresses, and the geographical distribution of attacks. These findings highlight critical areas for improving detection and response strategies. Understanding these patterns and implementing this information into security solutions, we can midigate further attacks.
